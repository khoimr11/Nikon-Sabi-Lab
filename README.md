# Sabi Lab · サビラボ

Brand book và bản mô phỏng gian hàng Shopee của **Sabi Lab** — nhà bán lẻ máy ảnh Nikon chính hãng.
**Chụp nhanh. Nhớ lâu.**

- `index.html` — trang tĩnh, không cần build. Có 3 tab: Brand Book, Gian hàng Shopee (mô phỏng), Listing Nikon Zf (mô phỏng).
- `img/` — ảnh sản phẩm, 8 ảnh Shopee và 7 ảnh phân loại màu.
- `logo/` — 5 phương án logo (SVG, bản sáng, tối, icon).

## Xem online bằng GitHub Pages
Settings → Pages → Source: **Deploy from a branch** → Branch: **main** / **(root)** → Save.
Sau 1–2 phút trang có tại `https://khoimr11.github.io/Nikon-Sabi-Lab/`.

Giao diện dùng hiệu ứng Liquid Glass (kính mờ, khúc xạ trên Chrome/Edge desktop) và hiệu ứng cuộn kể chuyện.
Hiệu ứng tự tắt khi người xem bật “giảm chuyển động”.
